# frontend-project
A collection of frontend practice projects, UI challenges, and technology experiments.

## Purpose
- Maintain all frontend practice work in one place.
- Try different UI challenge ideas and implementation styles.
- Experiment with different frontend technologies (HTML, CSS, JavaScript, React, and more).

## Branch and deployment workflow
- `main` is the source-of-truth branch where completed project code is kept.
- Create a separate branch for each project or deployment target (for example: `deploy/project-landing-page`, `deploy/react-dashboard`).
- Deploy from the related deployment branch so each project can be published independently.
- After a project is stable, merge updates back into `main`.

## Suggested structure for projects
Create one folder per project in the repository root, for example:
- `projects/ui-card-challenge`
- `projects/react-todo-app`
